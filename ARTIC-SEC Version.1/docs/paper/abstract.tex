ARTIC-Sec (Agentic Real-Time Intelligent Cybersecurity) is a SOC automation architecture that couples tabular intrusion detection, hybrid retrieval-augmented generation over MITRE ATT\&CK, and a LangGraph multi-agent workflow for investigation, containment recommendation, and NIST SP~800-61 reporting. The system is designed for air-gapped or on-premises deployments: inference uses ONNX Runtime for sub-100\,ms classification, embeddings default to MiniLM, and generation targets Llama~3.2~3B via Ollama. Guardrails enforce an action allow-list, prompt-injection detection, internal-IP protection, rate limits, and an append-only audit trail. We describe the data path from CIC-IDS2017 and synthetic telemetry through PostgreSQL, Qdrant, and Neo4j, and we specify evaluation protocols for latency (p95), detection quality (weighted F1), ablation of RAG/LLM/agent stages, and defensive prompt-injection tests. ARTIC-Sec treats agent execution as advisory by default, separating decisioning from infrastructure mutation so that human analysts remain the authority for high-severity containment.
